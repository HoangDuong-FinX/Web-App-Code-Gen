# Hotel Booking Notes

Generated by the WEB/APP Factory pipeline. Module Federation remote (track C):
the Host loads `probe_hotel_note/App` from `dist/remoteEntry.js`, same window, no
iframe.

```bash
npm install
npm run typecheck
npm run build      # emits dist/remoteEntry.js
npm test           # vitest, jsdom - src/App.test.tsx asserts the app mounts
```

Dependency versions are pinned exactly. This scaffold was installed, built and
tested before being committed; generated screens are added on top of it.

`npm test` starts as a single mount check. A type-check cannot see a crash on
mount, so keep that test and add one per generated screen; a passing mount test
is not the same as a working app - nothing here drives a real browser.
